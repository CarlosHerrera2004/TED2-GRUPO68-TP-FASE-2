# TED2-GRUPO68-TP-FASE
Proyecto correspondiente al TP Fase 2 de Tecnología del Diseño 2 (TED 2), Segundo Cuatrimestre 2026. Exploración de una experiencia de Realidad Aumentada web mediante MindAR + Three.js, accesible desde dispositivos móviles sin necesidad de instalar aplicaciones.  Alumnos: Magali Benitez, Santino Comas, Carlos Herrera, Missael Roldan.
